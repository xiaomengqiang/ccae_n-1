# InputNumber 计数器使用规范

用于直接输入或按固定步长调整数值。

## 使用规则

- **必须使用 `mode="spinner"` + `variant="outlined"`** 形态；其他形态（inline / borderless / filled 等）不要使用。
- `placeholder` 只用数字示例（如 `0`、`100`）。
- 显式设置宽度时，不低于 `6.5rem`。
- 达到边界时禁用对应增减操作，并校验空值、非数字和越界输入。

## Don't

- 不要缺少业务要求的边界校验。
- 不要用 InputNumber 表达复杂范围；使用两个明确字段或专用范围组件。
- 不要手动改写增减按钮样式。
- 不要使用 `addonAfter` 或 `suffix` 附加单位/后缀内容；单位等附加信息放控件外的独立文本。
- 不要使用 `prefix` 前缀装饰；左侧附加内容用控件外的独立文本。
- 不要使用开发组件不存在的属性或枚举值。
