# 首页视觉样板 v1

打开 `review.html` 可在“实现效果 / 高保真原图 / 叠加对照”之间切换；叠加时可调原图透明度。检查工具在样板外，不影响业务页面。

`首页样板.html` 为独立离线文件：内嵌 HarmonyOS Sans SC、图标和设计提供的图片，无 CDN 或远程接口。以 1920×1080 等比缩放，未改动旧 demo。

## 本轮范围

- 单页：基础设施—故障数，固定为光链路、Qwen 两条人工待办的状态，便于视觉比较。
- 导航、标题、指标、事件、时间轴和输入框为 HTML/CSS 组件，非整页截图覆盖。
- 机柜和人物直接复用用户设计包中的原始插画；本轮机柜内部为静态素材，尚未接动态拓扑。
- 已接守护 Tab、时间范围、故障/隐患选择、问答输入、时间轴提示、品牌重置。
- 其他页面入口、全故事线自动播放、机柜翻转和主题切换尚未接入；按钮保留视觉但禁用。避免在视觉样板中虚构详情和新剧情。
- 问答为旧 demo 的预设本地模拟，不连接真实 Agent。

## 已知视觉 / 数据边界

- 待办数按两条实际事件显示 2；原画板为 0。事件时间按 demo 待办文案显示“刚刚”。
- 分类标题按本次视觉画板使用“基础设施”；内部业务含义仍对应 demo 的 resource。
- 当前使用 20 个画板刻度作视觉验证，完整版本应按既有时间轴时序规则接入。
- 左侧轮廓、趋势线及背景渐变按设计尺寸重建，尚未获得浏览器像素对比结论，不宣称像素级还原。
- 为方便首轮看图，未加入装饰性自动动效；收到指定参数后接入。

## 如何反馈

优先反馈四类差异：1. 区块位置/比例；2. 字体大小/粗细；3. 背景/面板/边框；4. 图标、人物与机柜大小。

可用“左侧守护面板，字体偏大”“机柜整体偏上”等表述，或在截图上标注。先确认这一页，下一轮只针对这些差异修正，再扩展其他场景。

## 可复用源文件

`page.html`、`style.css`、`main.js` 为样板源文件；`build.py` 读取已提供的本地素材并打包成单文件。没有追加旧 demo 的补丁逻辑。
